# پروژه Todo

این پروژه یک برنامه ساده Todo است که به شما امکان می‌دهد وظایف خود را مدیریت کنید. شما می‌توانید وظایف جدید اضافه کنید، وظایف موجود را حذف کنید و لیست وظایف خود را مشاهده کنید.

## ویژگی‌ها

- افزودن وظیفه جدید
- حذف وظیفه
- نمایش لیست وظایف

## نحوه استفاده

1. برنامه را اجرا کنید.
2. گزینه مورد نظر خود را انتخاب کنید:
   - 1: افزودن وظیفه
   - 2: حذف وظیفه
   - 3: نمایش لیست وظایف
   - 4: خروج
3. دستورالعمل‌های روی صفحه را دنبال کنید.

## نیازمندی‌ها

- یک کامپایلر C++ (مانند g++)
  
## نحوه کامپایل و اجرا

برای کامپایل برنامه، از دستور زیر استفاده کنید:

```
g++ main.cpp -o todo
```

سپس برای اجرای برنامه، از دستور زیر استفاده کنید:

```
./todo
```
