# برنامه مدیریت کارها (Todo)

این برنامه یک برنامه ساده برای مدیریت کارها است که به شما امکان می‌دهد کارهای خود را اضافه کنید، حذف کنید، وضعیت انجام آن‌ها را تغییر دهید و لیست کارها را مشاهده کنید.

## ویژگی‌ها

- **اضافه کردن کار جدید**: می‌توانید یک کار جدید به لیست اضافه کنید.
- **حذف کار**: می‌توانید یک کار را از لیست حذف کنید.
- **تغییر وضعیت کار**: می‌توانید وضعیت انجام یا عدم انجام یک کار را تغییر دهید.
- **مشاهده لیست کارها**: لیست تمام کارهای موجود را مشاهده کنید.

## نحوه استفاده

1. برنامه را اجرا کنید.
2. از منوی اصلی یکی از گزینه‌های زیر را انتخاب کنید:
   - `1`: اضافه کردن کار جدید
   - `2`: حذف یک کار
   - `3`: مشاهده لیست کارها
   - `4`: تغییر وضعیت انجام/عدم انجام یک کار
   - `5`: خروج از برنامه
3. دستورات را طبق پیام‌های برنامه وارد کنید.

## پیش‌نیازها

- کامپایلر C++ (مانند `g++`) برای اجرای برنامه.
